01安装

shell
$ sudo install -dm755 /etc/apt/keyrings
$ curl -fsSL https://rnacos-img.qyzhg.cc/KEY.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/rnacos.gpg
$ echo "deb [signed-by=/etc/apt/keyrings/rnacos.gpg] https://rnacos-img.qyzhg.cc stable main" | sudo tee /etc/apt/sources.list.d/rnacos.list
$ sudo apt update
$ sudo apt install -y rnacos
$ sudo systemctl enable --now rnacos

命令中的域名随当前访问的源自动匹配（官方 GitHub Pages / Cloudflare 镜像均可），直接复制即可。装完由 systemd 托管、开机自启；控制台 http://<ip>:10848/rnacos/，默认账号 admin/admin（登录后请立即改密）。
